# Checklist antes de mostrar (slide a slide, olhando as imagens do preview)

**Conteúdo**
- [ ] Capa para o dedo: gancho curto, curioso/positivo, na voz dela (não é só o tema).
- [ ] 5–7 slides, uma ideia por slide; o CTA fecha a promessa da capa.
- [ ] Voz do `marca.md` (tom, emoji, minúsculas); nenhuma palavra proibida; nada de culpa/urgência falsa.
- [ ] Exemplos concretos; `[confirmar]` onde inventei algo que só ela sabe.

**Design**
- [ ] Cores e fontes só da marca (variáveis do tokens.css); display só em título grande; manuscrita só em comentário.
- [ ] Texto leve com UMA palavra forte por frase.
- [ ] Fundos alternam; escuro no máx. 1 slide; nenhum fundo sólido "vazio".
- [ ] Peças se sobrepõem, prints/fotos grandes e cortados; ≥ 1 peça diferente por slide; nada repetido > 2×.
- [ ] Cada elemento tem relação com o texto. Sem sombra.
- [ ] Nada cortado sem querer, nada cobrindo palavra, margens ~70px, texto legível no celular (corpo ≥ 36px).

**Entrega**
- [ ] Preview conferido por mim; editor/imagens enviados; ajustes aplicados e docs apagados.
- [ ] PNG final 2160×2700 só depois do "aprovado"; `legenda.md`; `_historico.md`; elementos novos salvos na marca.
